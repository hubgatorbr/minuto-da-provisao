# Fontes da tradução bíblica

A tradução selecionada para o catálogo é identificada internamente como `ALMEIDA_PUBLIC_DOMAIN`.

- Project Gutenberg, eBook 62383: https://www.gutenberg.org/ebooks/62383
  - Página identifica a obra como tradução portuguesa de João Ferreira d'Almeida e informa “Public domain in the USA”.
- Open Bibles, arquivo `por-almeida.usfx.xml`: https://github.com/seven1m/open-bibles/blob/master/por-almeida.usfx.xml
  - README do repositório lista “João Ferreira de Almeida” em português com licença “Public Domain”.

O aplicativo armazena o identificador da tradução, e não o texto bíblico integral. A troca futura deve ser feita no registro `shared/bible-translations.ts` e nos seeds, preservando as referências e as reflexões.
